Diário de Aula Virtual

App Android que substitui o caderno pessoal de uma professora dos anos iniciais e já é usado em sala de aula. Registra faltas em poucos toques, pendências de atividades, anotações por aluno, sondagens de escrita com a evolução de cada criança, metas da turma e fotos do dia. Os dados ficam só no aparelho, por respeito à LGPD, com backup na conta Google ou em arquivo.
  • Kotlin
  • Jetpack Compose
  • Material 3
  • MVVM
  • Room (SQLite)
  • Hilt
  • WorkManager
  • Coroutines e Flow

Queue Lab (em desenvolvimento)

Projeto back-end em desenvolvimento para estudar filas, workers e arquitetura assíncrona. A API coloca os jobs numa fila no Redis com BullMQ e um worker separado os processa, com novas tentativas em caso de falha e monitoramento pelo Bull Board. API, worker, Redis e PostgreSQL rodam em containers com Docker Compose.
  • Node.js
  • Typescript
  • BullMQ
  • Redis
  • PostgreSQL
  • Prisma
  • Docker

Video Game Match

Um jogo web no estilo jogo da velha, mas com video games no lugar do X e do O. Cada casa do tabuleiro cruza duas categorias, como gênero, plataforma, desenvolvedora ou ano de lançamento, e o jogador precisa citar um jogo que atenda às duas. A validação das respostas é feita no back-end com dados da API da IGDB.

Teste Técnico Full-Stack

Teste técnico feito para uma vaga de estágio full-stack: um app de transporte particular. O usuário informa a origem e o destino, a API calcula a rota com a Google Routes API e lista os motoristas disponíveis com o valor de cada viagem. Depois ele confirma a corrida e consulta o seu histórico. Front-end e back-end rodam em containers com Docker.
